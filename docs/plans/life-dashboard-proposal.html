Turning Unblock into a life dashboard

You asked for three things. The first is one screen that shows your life, projects and upcoming due dates. The second is bringing in notes from Keep, Samsung Notes, Apple Notes, Google Docs and Word. The third is triaging those hundreds of loose notes into real tasks and projects. This page shows how each would sit inside the Unblock you already have, and asks five questions. Nothing is built until you answer.

What already exists

Most of the foundation is already in Unblock

Two of your three asks are already on the roadmap as U5 Life overview and U7 Imports (docs/2-roadmap/Roadmap.md). Here is what each new piece reuses, and what it adds.

Reused as is
  • Projects, labels and colours, which become the dashboard's life areas.
  • Deadlines and their white, yellow and red stages (app/js/due-stage.js).
  • The Unsorted card's one-at-a-time flow (app/js/in-tray.js), which becomes the triage card.
  • Priority, GitHub sync and Gist sync, untouched.
New
  • An Overview screen in the left rail, beside Focus, Sort, Board and Projects.
  • A Notes library that holds imported notes, each tagged with where it came from.
  • An importer that reads exported files on your device.
  • A triage helper that spots tasks and dates inside a note.
Changed or cut
  • Nothing is cut.
  • The capture inbox stays for quick thoughts. Bulk imports go to the Notes library instead, so a few hundred notes never bury the Unsorted card.

Which piece comes first?

The three pieces depend on each other only loosely, so each can ship and be tested on its own.

1A Dashboard, then import, then triage Suggested

The Overview screen uses only data Unblock already holds, so it needs no new libraries and is the smallest piece. Triaged notes then have a place to show up.

1B Import and triage first, dashboard last

Starts with the part you called game changing. The catch is that your notes arrive before there is a calm screen to see the tasks they turn into.

What shape should the dashboard take?

2A Week strip and life areas Suggested

The mockup above. The next seven days show every dated task, and one card per area shows how much is open. It answers "what is coming and where am I behind" in one glance.

2B Month calendar

A familiar grid of dots, good for seeing a busy fortnight ahead. Undated tasks, which are most of a backlog, have nowhere to appear.

2C Project timeline

One bar per project from start to deadline. It looks impressive, but it needs start dates nobody records, and it is the hardest to read on a phone.

3

How should notes come in?

3A Export a file, drop it into Unblock Suggested

You export from each app, then drop the file (or a whole zip) onto an Import page. Unblock reads it on your device and uploads nothing. It works for all five sources, costs nothing, and works offline.

Needs three open-source libraries, which I am asking about rather than adding: JSZip to open zip files, mammoth to read Word files, and pdf.js to read PDFs. All three would be stored inside the app so imports still work offline.

3B Connect your accounts

Sign in to Google and Microsoft and pull documents directly. Apple Notes and Samsung Notes offer no way to do this, so you would still need to export a file (3A) for them.

Needs Google and Microsoft developer app registrations and their approval reviews. It is free, but it is weeks of setup for two of the five sources.

3C Paste text only

Copy a note, paste it into a box. Needs no libraries and is built in a day, but doing it hundreds of times is exactly the chore you want to avoid.

Where should imported notes live?

4A In a separate Notes library Suggested

Each note keeps its full text and its source. Triage turns parts of it into tasks that link back to the note, and the note stays as reference, so nothing is lost when one line becomes a task.

In the first version the library stays on the device you imported on. Tasks made from it sync to your other devices as they do now. Syncing the notes themselves is a later choice, because a few hundred notes would make the sync file several times larger.

4B Straight into the capture inbox

No new screen: every note becomes one Unsorted item. It is simpler to build, but 200 items would bury the quick thoughts you capture day to day, and a long note can only become one task.

5A Simple rules on your device Suggested

Checklists, bullets and numbered lines become task suggestions. Phrases like "by Friday", "20 Oct" or "end of month" become deadlines. Words matching a project name or label pick the project. It is free, private, offline and predictable, but it cannot understand a rambling paragraph.

5B Claude reads each note

You add your own Claude API key in Settings, and Claude splits prose into steps and suggests projects. It is far better with messy notes, but every note costs money and leaves your device. I would price it with real figures before building it.

5C Simple rules now (5A), then Claude as an optional button later (5B)

Rules handle the easy majority straight away. An "Ask Claude about this note" button is added later for the hard cases, and only if you still want it after trying the simple rules (5A).
